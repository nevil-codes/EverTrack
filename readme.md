
# EverTrack

**Smart Habit Tracking Application – Python Project**

## Overview
EverTrack is a Python-based desktop application designed to help users track their daily habits, monitor productivity, and analyze progress through interactive charts. The application is visually appealing, user-friendly, and demonstrates a combination of GUI, data storage, and visualization.

## Features
- Add habits along with duration or completion status  
- View organized habit logs in a clean table  
- Generate bar, line, and pie charts to analyze habits  
- Offline, lightweight, and easy to use  

## Technologies Used
- **Python 3** – Core programming language  
- **Tkinter** – GUI framework for creating the user interface  
- **Matplotlib** – Used for generating visual charts  
- **JSON** – Lightweight data storage  

## Why EverTrack?
- Simple yet visually polished and easy to present  
- Demonstrates Python GUI, data handling, and visualization skills  
- Practical application relevant to everyday productivity  

## How It Helps
EverTrack helps users build discipline, improve productivity, and stay organized by providing a visual insight into their habits and progress over time.

## Installation
1. Clone this repository:  
   ```bash
   git clone <repository_url>
   ```
2. Navigate to the project folder:  
   ```bash
   cd EverTrack
   ```
3. Install required libraries:  
   ```bash
   pip install matplotlib
   ```
4. Run the application:  
   ```bash
   python evertrack.py
   ```

## Usage
1. Open the application.  
2. Add your daily habits and their duration or completion status.  
3. View your habit log in the table.  
4. Generate visual charts to track your progress.
